# Windows-Event-Log-Incident-System-Auditor
Herramienta forense de solo lectura, para auditar, diagnosticar y correlacionar incidentes en Windows (Client 10/11 y Server 2012/2016/2019/2022/2025), este script procesa los eventos mediante streams de lectura/escritura volcando directamente a disco en formato CSV lo que proteje la RAM en servidores en producción con alta transaccionalidad.
